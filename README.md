# Python Operators

This project demonstrates different types of operators in Python.

## Operators Covered

- Arithmetic Operators
- Logical Operators
  - AND
  - OR
  - NOT
- Assignment Operators
- Relational Operators
- Bitwise Operators
- Identity Operators

## Concepts Practiced

- Mathematical operations
- Boolean logic
- Comparison operations
- Assignment operations
- Bitwise operations
- Identity checking using `is` and `is not`

## Language

Python
